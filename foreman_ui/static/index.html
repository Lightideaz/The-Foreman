How the manager proves work (verify commands)

    
These run on your computer, outside the sandbox, when the manager runs verify after reading the diff.

    

    
    
Extra commands the executor may not run (deny rules)

    
Git writes, network tools, shells and common package managers are always blocked. These add the ones your stack uses.

    

    
Paths that need your approval to change (protected paths)

    
A change here is flagged as a warning in the round's report.
