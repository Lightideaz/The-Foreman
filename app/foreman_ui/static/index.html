Guide

How The Foreman splits the work between you, your manager agent and the executor.

How it works

  1. Your manager agent writes a task. Scope, acceptance criteria and the commands that prove it.
  2. The executor builds it in a sandbox. On its own branch, with no network.
  3. The manager reads the diff and verifies. Your test commands, run by The Foreman.
  4. Only then is it accepted. One commit on your base branch. Nothing is pushed.
